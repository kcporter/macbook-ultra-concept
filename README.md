# MacBook Ultra Concept

An unofficial, interactive 3D design concept for a thin convertible MacBook Ultra, built as a single HTML page with CSS 3D transforms and no dependencies.

- Hinge postures: Closed, Laptop, Flat, Tent, and a full 360° fold, with smooth transitions
- Drag to orbit, scroll or pinch to zoom, keyboard controls on the 3D view
- Bead-blasted aluminum finish rendered per face, edge-lit haptic trackpad, light and dark themes
- A rumor board summarizing reporting on Apple's first OLED Mac, with concept extras clearly labeled

Open `index.html` in a browser, or visit the deployed site.

Unofficial fan concept. Not affiliated with or endorsed by Apple. Rumor details are attributed in the page and reflect reporting as of October 2026.
